# 版本计划

## V0.1 — 独立可用基线（已实现）

- 原生菜单栏 App，可独立启动和退出。
- RC003 连接识别与完整按键诊断。
- 固定签名与输入监控／辅助功能权限引导。
- 默认、mmTV、浏览器和 IINA 内置 Profile。
- 前台 App 自动切换 Profile。
- 键盘快捷键、系统音量和媒体动作。
- 登录启动、暂停服务、睡眠唤醒重连。
- 单元测试覆盖 usage 映射、Profile 解析、优先级和重复策略。

验收标准：不启动 mmTV，在 MacBook 上可以只靠遥控器完成浏览器或 IINA 的核心播放导航；启动 mmTV 后同一遥控器能够控制其主要页面，且按键不双触发。

当前自动化验收已覆盖构建、签名、RC003 usage、Profile 路由、mmTV 键盘注入映射和配置编解码；Finder 前台切换已实机验证。mmTV 实体回归与第三方应用手感仍待人工验收。

## V0.2 — 可靠接管与可配置（已实现）

- 可视化 Profile 编辑器。
- 每个应用分别配置单击、长按和双击。
- 完整三槽 HID Report 解析和按键状态差分。
- 设备级 `hidutil` 中转映射、第三方映射保留和异常退出恢复。
- 映射失败时自动回退关联去重模式。
- 可调长按、双击和防抖时间。
- 遥控器电量、固件、连接与接管状态。
- Profile 与运行设置原子写入、损坏恢复和恢复默认。
- Finder、主流浏览器、IINA 和 mmTV 内置 Profile。
- 最近事件诊断。

## V0.3 — 语音输入（已实现）

- 语音键从 App Profile 中抽离为全局提供商通道。
- Typeless 通过真实硬件 F20 事件触发。
- macOS 系统听写作为原生降级提供商。
- 控制台与菜单栏展示当前提供商，运行设置持久化且兼容 V0.2 配置。

## V0.4 — 应用级增强

- 为普通快捷键无法覆盖的应用提供受控 App Adapter。
- 评估 mmTV 的版本化本机 IPC，保留键盘 Profile 作为降级路径。
- 按键学习、Profile 导入／导出和有限的结构化动作序列。

## 暂缓

通用游戏手柄平台、虚拟 HID 驱动、云同步、在线 Profile 商店、任意 Shell/JavaScript 脚本，均在真实需求出现后再评估。
